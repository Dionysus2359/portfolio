# Om Tiwari Portfolio

Personal portfolio built with Next.js, TypeScript, React, GSAP and CSS Modules. Includes responsive architectural artwork, case studies, accessible motion preferences and a contact form that prepares an email draft.

## Development

```sh
npm ci
npm run dev
```

Development runs at `http://127.0.0.1:3000`. The test and measurement commands use Node.js native TypeScript support.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run typecheck` | Generate Next.js declarations and check TypeScript |
| `npm run build` | Build the static site into `out/` |
| `npm test` | Run regression checks; build first for exported-page checks |
| `npm run preview` | Serve `out/` locally at `http://127.0.0.1:3001` |
| `npm run check:bundles` | Measure built JavaScript, CSS, fonts and hero asset sizes |

The two files in `scripts/` support local preview and asset-size reporting. Vercel builds with `npm run build`; neither script is needed to serve the deployed site.

## Project structure

- `src/app/`: routes, metadata and global styles.
- `src/components/`: page sections, loading screen, motion and monitoring.
- `src/content/`: identity, project copy and artwork configuration.
- `src/lib/` and `src/types/`: shared behavior and types.
- `public/`: production media, fonts and their license files.
- `tests/`: regression checks for contact drafts, loading recovery, metadata, motion and shipped media. These belong in version control and are not included in the static export.

Design drafts, prompts, source masters, screenshots and old hosting material are archived locally under the ignored `plans_docs/` directory. The build, tests and measurement script use committed source and production assets only.

## Deployment

Deploy `main` on Vercel using the Next.js framework preset. The project produces a static export with no email-server credentials required.

Set `NEXT_PUBLIC_SITE_URL` to the plain production origin, or leave it empty to use Vercel's automatic `VERCEL_PROJECT_PRODUCTION_URL`. Do not paste Markdown or a path into the value. Canonical links, social metadata and the sitemap are generated at build time, so environment changes require a new deployment. See `.env.example`; real environment files stay untracked.

Vercel Analytics and Speed Insights run only in production. Enable Web Analytics in the Vercel dashboard and confirm collection after deployment. The integrations remove query strings and fragments from reported page URLs and do not send contact-form contents or custom events.

Next.js manages `next-env.d.ts`; it is regenerated by development, typecheck and build commands. Dependencies, generated output and local notes stay ignored.
