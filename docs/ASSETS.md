## Add photography

1. Put approved photos below `public/media/people/` or `public/media/projects/adobe/`.
2. Add a typed record in `src/content/profile.ts` (portrait) or the Adobe project's `photographs` array in `src/content/projects.ts`.
3. Include actual dimensions, meaningful alternative text, optional accurate caption/credit, and crop positions for desktop and mobile. Crop positions use CSS object-position, e.g. `"50% 35%"`.
4. The editorial portrait layout uses an asymmetrical desktop grid, a 4:5 frame, a mobile-specific crop and a restrained vermilion rule. Hero portrait use remains opt-in.

No synthetic portrait, fabricated event scene, invented testimonial, or unverified before/after visual is included.
